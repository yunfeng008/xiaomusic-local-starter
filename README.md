# xiaomusic-local-starter

[xiaomusic](https://github.com/hanxi/xiaomusic)（小爱音箱播放本地音乐，MIT）的**裸机直跑一键包**：不想用 Docker、想直接在 Mac/电脑上跑起来的，`bash start.sh` 一条命令搞定，已预修下面 6 个不写出来就得自己摸半天的坑。

> 官方主推 Docker 部署，本包是给裸机直跑用户的补充方案，不是替代品。工具本体全是 xiaomusic 项目的，本包只是一份"踩过坑之后"的启动脚本和默认配置。

## 快速开始

```bash
bash start.sh          # 首次运行自动装依赖（需 Python 3.10+，装有 uv 会自动用）
# 打开 http://localhost:8090 → 设置页填小米账号密码 → 选择音箱
# 然后对音箱说：「播放歌曲 小星星」
```

往 `music/` 文件夹里丢音频文件（mp3/m4a 都行），**文件名就是点歌名**；下载功能在网页「设置 → 下载工具」，贴 B站视频链接即可。

## 这个包帮你修好的 6 个坑

| # | 现象 | 原因 | 本包的处理 |
|---|------|------|-----------|
| ① | 对音箱喊"播放歌曲XX"，小爱还是播小米的默认内容 | `enable_pull_ask` 默认 `false`，程序根本不监听语音记录 | 配置里默认开启 |
| ② | 口令截获成功、小爱说"播放失败请换个网络" | `public_port` 默认 58090 是 Docker 端口映射用的，裸机上没人监听 | 自动设为与真实端口一致 |
| ③ | 网页下载歌曲必失败 | `ffmpeg_location` 默认 `./ffmpeg/bin` 不存在 | 自动探测本机 ffmpeg 路径（没有会提示装） |
| ④ | 下载报 `FileNotFoundError: yt-dlp` | 程序按裸命令名启动 yt-dlp，服务进程 PATH 里没有 venv/bin | start.sh 把 `.venv/bin` 加进 PATH |
| ⑤ | 8090 端口被占、启动即退 | 端口冲突 | 换个端口：编辑 config.json 的 `port` 即可 |
| ⑥ | PyPI 直连超时（国内网络） | 网络问题 | 安装失败自动切清华镜像 |

## 已知限制（裸跑模式的天然属性，不是 bug）

- **电脑休眠/合盖 = 服务断**，播放时保持唤醒；想 7×24 就部署到 NAS/服务器（用官方 Docker 方案）
- **路由器重新分配 IP 后**音箱拉不到流（现象同②），在网页设置里把 hostname 改成新 IP 即可；在路由器里给电脑绑固定 IP 可根治
- **B站"搜索歌名"下载会被 412 反爬拦截**（无 cookie），**贴视频链接下载没问题**；歌单下载个别分P失败时会整体报"失败"，但文件其实大多已下好——喊一句"刷新列表"就有了
- **换歌必须换视频链接**：文件名只是标签，内容来自链接；同文名再下载会被静默跳过并报成功

## 隐私与内容

- `conf/`（含你的小米账号、登录 token）、`music/`（你的音频）、`config.json`（含内网 IP）已全部写进 `.gitignore`， fork/上传仓库不会带上它们
- 本包不含任何音频内容；请勿分发从视频平台下载的受版权保护的音乐
